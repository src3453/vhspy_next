# MUSEアナログハイビジョン再現計画

## 目的

NHKが開発したMUSE（Multiple Sub-Nyquist Sampling Encoding）方式の信号処理とアナログ伝送を、ソフトウェアで段階的に再現する。まず放送衛星用MUSEの規格信号をエンコード／デコードできるようにし、その後に伝送路劣化、衛星FM、音声・データ多重を追加する。

仕様の基準は **ITU-R勧告 BO.786（1992年版）** とする。Narrow MUSEやMUSE/NTSC変換などは別方式・別機能として扱い、初期実装の仕様に混ぜない。

## MUSE方式の理解

MUSEは、映像をデジタル処理でサブサンプリングし、D/A変換したアナログ信号として伝送する方式である。したがって、方式再現の中心はデジタル映像処理と、サンプル値アナログ伝送路のモデル化にある。

基本的な信号経路は次のとおり。

```text
1125/60i ハイビジョン入力
  → 輝度・色差信号への変換、準定輝度処理
  → 静止／動領域に応じたサブサンプリングと動き補償
  → 輝度・色信号のTCI時分割多重、同期・制御信号の挿入
  → D/A変換相当のサンプル値アナログ信号
  → （任意）伝送路、衛星FM
  → （任意）FM復調、波形等化、同期・クロック再生
  → TCI分離、補間、動き適応処理
  → 1125/60i映像出力
```

## 基本仕様

| 項目 | 計画で採用する基準 |
|---|---|
| 映像走査 | 1125本、30フレーム／秒、60フィールド／秒、インターレース、16:9 |
| ライン周波数 | 33.75 kHz |
| 伝送サンプリング周波数 | 16.2 MHz。1ラインあたり480サンプル、1フレームあたり540,000サンプル |
| 映像帯域 | おおむね30 MHzのハイビジョン信号を、8.1 MHzのベースバンド信号に圧縮 |
| 輝度のサンプリング | フィールド間・フレーム間のオフセットを用いた多重サブサンプリング。静止領域は複数フィールドを合成し、動領域はフィールド内補間を基本にする |
| 色信号 | R−YとB−Yをライン順次で送り、時間圧縮して輝度信号と時分割多重する |
| 信号レベル | 8ビット値を基本とする。輝度の黒16、灰色128、白クリップ239。色信号の無彩色レベルは128 |
| 同期・制御 | 正極性同期、フレームパルス、サブサンプリング位相・動きベクトル等の制御情報、VIT信号を含む |
| 衛星伝送 | FM。ベースバンド帯域8.1 MHz、衛星チャンネル帯域24または27 MHz |
| 音声 | Mode Aは4ch／32 kHz、Mode Bは2ch／48 kHz。音声とデータはデジタル多重 |

標準仕様では、色信号を約1/4に時間圧縮し、R−YとB−Yを奇数・偶数ラインに割り当てる。色信号は輝度に対して4ライン分進めて配置される。輝度信号には動き補償を適用し、動きベクトルやサンプリング位相などを制御信号として伝える。

衛星FMを再現する場合は、ベースバンド信号だけでなく、24／27 MHzチャンネル、FM偏移、正極性、 keyed AFC、エネルギー拡散を別パラメータとして扱う。実際の12 GHz搬送波を生成する必要はなく、複素包絡線またはIF相当のモデルで伝送劣化を評価できる。

## 実装方針

### スコープ

初期対象は、MUSEのベースバンド・エンコーダ／デコーダとする。実際の衛星RF、音声・データの誤り訂正、放送サービスの運用機能は後続段階にする。

現リポジトリのVHS Nextは、README上ではNTSCコンポジット信号とVHS記録・再生経路を扱っている。MUSEは走査形式、信号帯域、同期方式が異なるため、既存のNTSC信号経路に直接混ぜず、独立した信号処理モジュールとして追加する。MUSEをテープ記録まで再現する場合は、通常のVHS経路へ流用せず、MUSE対応記録機器やW-VHS等の別モデルとして設計する。

### モジュール構成案

Rustの信号処理層に、VHS処理から独立した`muse-core`相当のモジュールを設ける。

```text
muse-core/
  format       ライン、フィールド、フレーム、クロック定義
  encoder      輝度・色信号、サブサンプリング、TCI、同期・制御信号
  decoder      同期・制御信号検出、TCI分離、補間、出力変換
  motion       動き検出、動きベクトル、静止／動領域の混合
  channel      帯域制限、遅延、雑音、サンプル位相ずれ、FM（後続段階）
  audio_data   音声・データ多重（後続段階）
```

内部データは、信号レベルとフィルタ演算に十分な精度を持つ`float32`以上で保持する。規格どおりの8ビット量子化、D/A相当の波形化、伝送路劣化は別段に分け、理想伝送とアナログ劣化ありの比較ができるようにする。クロックは浮動小数の累積で近似せず、ライン周波数を基準とする整数または有理数の位相で管理する。

## 実装段階

### Phase 0：仕様・インターフェースを固定

- ITU-R BO.786を対象信号仕様として採用する。
- 入力・出力の走査形式を1125/60iに固定し、フィールド番号、フィールド位相、ライン番号を明示する。
- 1080i、1080p等の入力を受ける場合は、MUSE処理とは分離したフォーマット変換を前段に置く。
- テストパターンとして静止チャート、ゾーンプレート、色バー、一定速度のパン、独立して動く物体を用意する。

**完了条件：** クロック、ライン、フィールド、信号レベル、処理境界をコード上の型と設定に落とし込める。

### Phase 1：理想条件の静止画ベースバンド往復

- ライン／フレーム構造と16.2 MHzのサンプル列を実装する。
- 輝度と色差信号、TCI配置、同期・フレームパルスを実装する。
- 4フィールド周期のサンプリング位置と静止画補間を実装する。
- 色信号の時間圧縮、ライン順次配置、色と輝度の分離・再構成を行う。

**完了条件：** 伝送路劣化なしで、静止した細線・高周波チャートが複数フィールドの情報から再構成され、フィールド位相を変えても同期と位置が崩れない。

### Phase 2：動き適応と動き補償

- 動き検出と静止／動領域の混合を実装する。
- 制御信号上の動きベクトルとサブサンプリング位相を扱う。
- まず一定方向・一定速度のパンで補償を確認し、次に局所的に動く物体を加える。
- ベクトルが不正または未指定の場合の復号動作を定義する。

**完了条件：** 静止背景の解像度を保ちつつ、動領域は規格に沿う補間となり、動きに応じて予測可能な解像度低下が現れる。動きベクトルを誤らせた場合の残像や位置ずれも確認できる。

### Phase 3：サンプル値アナログ伝送路

- D/A後の再構成フィルタと帯域制限をモデル化する。
- 利得、群遅延、雑音、非線形性、サンプル位相ずれを個別に加えられるようにする。
- VIT信号等を使った波形等化と、受信側の同期・サンプルクロック再生を実装する。
- 規格どおりの8ビット量子化を切り替え可能にする。

**完了条件：** 小さな遅延・雑音・帯域劣化を段階的に加えたとき、同期と復号品質が連続的に変化し、設定値から現象を説明できる。

### Phase 4：衛星FM伝送

- 8.1 MHzベースバンドからFM変調・復調を実装する。
- 24／27 MHzのチャンネル条件、FM偏移、極性、エネルギー拡散をパラメータ化する。
- 搬送波の代わりに複素ベースバンドまたはIF表現を使い、必要な場合だけ高いサンプルレートで波形を生成する。

**完了条件：** FM帯域、雑音、周波数偏移の変更が、受信後の画質・同期に与える影響を再現できる。

### Phase 5：音声・データ多重とUI連携

- Mode A／Bの音声形式、フレーム、制御情報を実装する。
- BCH等の誤り訂正、データチャンネルを追加する。
- GUIには、MUSE信号生成、チャンネル劣化、復号、映像出力を独立した操作として接続する。

**完了条件：** 映像とは独立に音声・データの多重と復元を確認でき、GUIから段階別の信号を比較できる。

## 検証方法

各Phaseで、入力パターンと復号結果だけでなく、ライン波形、サンプル位相、制御信号、フィールド番号を保存・可視化する。最低限、以下を確認する。

- **静止解像度：** 細線、斜線、ゾーンプレートで4フィールド分の標本位置が正しく使われる。
- **動き：** パンと移動物体で、動き補償の有無・方向・誤差の影響を比較できる。
- **色：** 色バーと高彩度パターンで、ライン順次色信号の誤分離やY/C漏れを確認する。
- **同期：** フレーム開始、フィールド位相、サンプルクロックずれの復帰動作を確認する。
- **伝送路：** 帯域制限、遅延、雑音、FM条件を一つずつ変え、劣化の原因を切り分ける。
- **規格値：** 信号レベル、サンプル数、制御ビット、FM条件をITU仕様と照合する。

公開仕様と合成テストパターンで方式の実装は進められるが、実機に近い最終画質を評価するには、既知のMUSE信号または実機デコーダ出力との比較が必要になる。
